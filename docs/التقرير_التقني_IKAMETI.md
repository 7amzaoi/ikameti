## 1. الملخّص التنفيذي

**IKAMETI** منصّة ويب احترافية متعددة اللغات تقدّم خدمات استشارية متكاملة للإقامة والسكن والخدمات القانونية في تركيا. صُمّم المشروع لخدمة شريحة واسعة من المهاجرين والمقيمين من جنسيات مختلفة، لذلك يدعم **ثماني لغات** بواجهات تتكيّف تلقائياً مع اتجاه الكتابة (يمين-يسار ويسار-يمين).

يتكوّن النظام من **واجهة أمامية عامة** للزوّار، و**لوحة تحكم إدارية** متصلة بقاعدة بيانات سحابية لإدارة المحتوى والطلبات، مع تطبيق **معايير تحسين محركات البحث (SEO) الكاملة** لضمان الظهور في نتائج البحث، والنشر الفعلي على استضافة حقيقية بنطاق مخصّص.

---

## 2. مشكلة المشروع والأهداف

### المشكلة
إجراءات الإقامة في تركيا معقّدة إدارياً، ومتغيّرة باستمرار، وموزّعة على جهات متعددة، ويصعب على المهاجر — خصوصاً غير الناطق بالتركية — متابعتها دون أخطاء قد تكلّفه الوقت أو رفض الطلب.

### الأهداف
- بناء منصّة رقمية **تبسّط** خدمات الإقامة وتقدّمها بخطوات واضحة.
- **كسر حاجز اللغة** عبر دعم لغات متعددة تخدم الجاليات المستهدفة.
- توفير **قناة تواصل ذكية** (نماذج + واتساب) بين العميل والفريق.
- تمكين إدارة المحتوى (مدوّنة/أخبار) و**متابعة الطلبات** عبر لوحة تحكم.
- تطبيق **أفضل ممارسات تحسين محركات البحث** لتحقيق ظهور رقمي قوي.

## 4. التقنيات المستخدمة (Technology Stack)

| الطبقة | التقنية | الاستخدام |
|--------|---------|-----------|
| **الواجهة الأمامية** | HTML5 · CSS3 · JavaScript (Vanilla ES6+) | بناء الصفحات والتفاعلات دون أطر ثقيلة لضمان السرعة |
| **تعدد اللغات** | نظام i18n مخصّص (JSON) | ترجمة ديناميكية للمحتوى حسب اللغة المختارة |
| **قاعدة البيانات** | Supabase (PostgreSQL) | تخزين المدوّنات والأخبار والطلبات سحابياً |
| **الأمان** | Row-Level Security (RLS) | سياسات صلاحيات على مستوى الصف بقاعدة البيانات |
| **محرّر النصوص** | Quill.js | محرّر غني لكتابة المقالات في لوحة التحكم |
| **الرسوم البيانية** | Chart.js | إحصائيات ومؤشرات في لوحة التحكم |
| **إدخال الهاتف الدولي** | intl-tel-input | حقل هاتف بأكواد الدول والتحقق من الصحة |
| **التحليلات** | Google Analytics 4 (GA4) | تتبّع الزوّار وسلوكهم |
| **الخادم/الاستضافة** | Apache على Hostinger | استضافة مشتركة + ملف `.htaccess` |
| **إدارة الإصدارات** | Git + GitHub | تتبّع التغييرات والنسخ الاحتياطي |
| **النطاق و DNS** | GoDaddy | إدارة نطاق `ikameti.com.tr` وربطه بالاستضافة |

> **ملاحظة معمارية:** اختير أسلوب **الموقع الثابت (Static Site)** مع منطق من جهة العميل + قاعدة بيانات سحابية (نمط Jamstack)، ما يوفّر سرعة تحميل عالية، وتكلفة استضافة منخفضة، وأماناً أعلى (لا يوجد خادم تطبيقات معرّض للاختراق).

## 6. الميزات الرئيسية

### 6.1 نظام تعدد اللغات (i18n)
- دعم **8 لغات**: الإنجليزية، العربية، التركية، الروسية، الفارسية، الأوزبكية، الدرّية، والتركمانية.
- **تبديل فوري** للّغة دون إعادة تحميل الصفحة، مع حفظ تفضيل المستخدم.
- **دعم اتجاه الكتابة RTL/LTR** تلقائياً (العربية/الفارسية/الدرّية من اليمين لليسار).
- صفحات مُهيّأة لكل لغة (SEO pages) بروابط مستقلة لتحسين الفهرسة.

### 6.2 معالج طلب الإقامة (Residency Wizard)
معالج تفاعلي متعدد الخطوات يجمع بيانات العميل (نوع الإقامة، الحالة، المدة، عقد الإيجار، عدد أفراد الأسرة، بيانات التواصل) بواجهة سلسة مع مؤشر تقدّم، وقوائم منسدلة مخصّصة التصميم، وحالة تحميل عند الإرسال.

### 6.3 نظام الأخبار (News Carousel)
شريط أخبار ديناميكي أسفل الواجهة، بارتفاع ثابت لضمان تناسق الصفحة، مع خاصية "عرض المزيد" للأخبار الطويلة، وتبديل تلقائي، وترجمة لكل خبر.

### 6.4 المدوّنة (Blog)
نظام مدوّنة متكامل بمقالات مُدارة من قاعدة البيانات، مع تصنيفات، وصور غلاف مخصّصة لكل لغة، وبيانات وصفية (Meta) وبيانات مُهيكلة (Schema) لكل مقال.

### 6.5 خدمة التذكير (Remind Me)
نموذج يتيح للعميل إدخال بياناته ليصله تذكير قبل انتهاء إقامته بشهرين — قناة لجمع العملاء المحتملين (Lead Generation).

### 6.6 التكامل مع واتساب
أزرار تواصل تفتح محادثة واتساب **برسالة جاهزة مُعبّأة تلقائياً بلغة العميل** تتضمّن اسمه وتفاصيل طلبه — من الواجهة ومن لوحة التحكم.

### 6.7 بطاقات التسعير (Pricing)
ثلاث باقات خدمات (مبتدئة / كاملة / حزمة الاستقرار) بأسعار وميزات واضحة وشفّافة، مع خدمات إضافية اختيارية.

## 7. لوحة التحكم الإدارية (Admin Dashboard)

لوحة تحكم متكاملة مبنية بـ JavaScript، تتيح للمسؤول:

- **إدارة المدوّنة:** إضافة/تعديل/حذف المقالات بمحرّر غني (Quill)، مع إدخال ترجمة كل مقال في **7 لغات** وصور غلاف مستقلة لكل لغة.
- **إدارة الأخبار:** نشر الأخبار مع ترجماتها والتحكم بإظهار/إخفاء التاريخ.
- **متابعة الطلبات:** عرض طلبات الإقامة وطلبات التذكير الواردة من الموقع بنظام لوحة (Kanban) مع مؤشر الأيام المتبقية.
- **رسائل واتساب الذكية:** زر لكل طلب يفتح محادثة برسالة احترافية جاهزة بلغة العميل.
- **الإحصائيات:** رسوم بيانية (Chart.js) لعرض المؤشرات.

## 8. تصميم قاعدة البيانات (Database Schema)

قاعدة بيانات **PostgreSQL** عبر منصّة **Supabase**، تتكوّن من الجداول التالية:

| الجدول | الوظيفة |
|--------|---------|
| `categories` | تصنيفات المدوّنة |
| `blogs` | المقالات + عمود `translations` (JSONB) للترجمات متعددة اللغات |
| `news` | الأخبار + الترجمات + التحكم بإظهار التاريخ |
| `residency_submissions` | طلبات الإقامة الواردة من الموقع |
| `reminder_submissions` | طلبات خدمة التذكير |

### الأمان — سياسات RLS (Row-Level Security)
طُبّقت سياسات صلاحيات دقيقة على مستوى الصف:
- **قراءة عامة** للمحتوى المنشور فقط (المدوّنات/الأخبار).
- **إدخال عام** للطلبات (يستطيع الزائر إرسال طلب فقط).
- **قراءة/تعديل/حذف** الطلبات والمحتوى **للمسؤول المُصادَق عليه فقط**.

هذا يضمن أن الزائر لا يمكنه الاطّلاع على بيانات العملاء أو تعديل المحتوى.

## 9. تحسين محركات البحث (SEO)

طُبّقت منظومة SEO تقنية متكاملة:

| العنصر | التطبيق |
|--------|---------|
| **خريطة الموقع** | `sitemap.xml` بـ 48 رابطاً مع بدائل اللغات |
| **robots.txt** | توجيه محركات البحث + رابط الخريطة |
| **الروابط القانونية (Canonical)** | لكل صفحة لتفادي المحتوى المكرر |
| **hreflang** | ربط نسخ اللغات الثماني + `x-default` |
| **البيانات المهيكلة (JSON-LD)** | Organization · WebSite · LocalBusiness · BlogPosting · BreadcrumbList |
| **بيانات وصفية مترجمة** | عناوين وأوصاف Meta لكل لغة |
| **Open Graph / Twitter Cards** | معاينات احترافية عند المشاركة |
| **Google Analytics 4** | تتبّع الأداء والزوّار |
| **Google Search Console** | توثيق الملكية وإرسال الخريطة وطلب الفهرسة |

## 10. الأداء والأمان

- **`.htaccess`**: فرض HTTPS، توحيد النطاق (www ← non-www)، ضغط GZIP، تخزين مؤقت (Caching) ذكي، ورؤوس أمان (Security Headers).
- **صفحة خطأ 404 مخصّصة** بهوية الموقع.
- **معمارية ثابتة** تقلّل أسطح الهجوم (لا خادم تطبيقات).
- **HTTPS** مفعّل (شهادة SSL).
- **فصل الصلاحيات** عبر RLS في قاعدة البيانات.

---

## 11. النشر والاستضافة (Deployment)

1. بناء نسخة نشر نظيفة (ZIP) تحتوي ملفات الإنتاج فقط.
2. رفعها على استضافة **Hostinger** المشتركة (مجلد `public_html`).
3. ربط النطاق الخارجي **`ikameti.com.tr`** المُدار عبر **GoDaddy** بالاستضافة عبر تعديل خوادم الأسماء (DNS/NS).
4. تفعيل **HTTPS**، وتوثيق الموقع في **Google Search Console**، وربط **GA4**.
5. الموقع يعمل حالياً بشكل مباشر على الإنترنت. ✅

## 16. الخاتمة
