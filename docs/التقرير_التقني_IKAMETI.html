1. الملخّص التنفيذي

IKAMETI منصّة ويب احترافية متعددة اللغات تقدّم خدمات استشارية متكاملة للإقامة والسكن والخدمات القانونية في تركيا. صُمّم المشروع لخدمة شريحة واسعة من المهاجرين والمقيمين من جنسيات مختلفة، لذلك يدعم ثماني لغات بواجهات تتكيّف تلقائياً مع اتجاه الكتابة (يمين-يسار ويسار-يمين).

يتكوّن النظام من واجهة أمامية عامة للزوّار، ولوحة تحكم إدارية متصلة بقاعدة بيانات سحابية لإدارة المحتوى والطلبات، مع تطبيق معايير تحسين محركات البحث (SEO) الكاملة، والنشر الفعلي على استضافة حقيقية بنطاق مخصّص.

2. مشكلة المشروع والأهداف

المشكلة

إجراءات الإقامة في تركيا معقّدة إدارياً، ومتغيّرة باستمرار، وموزّعة على جهات متعددة، ويصعب على المهاجر — خصوصاً غير الناطق بالتركية — متابعتها دون أخطاء قد تكلّفه الوقت أو رفض الطلب.

الأهداف

  • بناء منصّة رقمية تبسّط خدمات الإقامة وتقدّمها بخطوات واضحة.
  • كسر حاجز اللغة عبر دعم لغات متعددة تخدم الجاليات المستهدفة.
  • توفير قناة تواصل ذكية (نماذج + واتساب) بين العميل والفريق.
  • تمكين إدارة المحتوى ومتابعة الطلبات عبر لوحة تحكم.
  • تطبيق أفضل ممارسات تحسين محركات البحث لتحقيق ظهور رقمي قوي.

3. الفئة المستهدفة

المهاجرون والمقيمون والراغبون في الإقامة بتركيا من الجنسيات العربية والتركية والروسية والفارسية والأوزبكية والأفغانية والتركمانية والناطقة بالإنجليزية — من طلاب، ومستثمرين، وعائلات، ومقيمين جدد.

6. الميزات الرئيسية

6.1 نظام تعدد اللغات (i18n)

  • دعم 8 لغات: الإنجليزية، العربية، التركية، الروسية، الفارسية، الأوزبكية، الدرّية، التركمانية.
  • تبديل فوري للّغة دون إعادة تحميل، مع حفظ تفضيل المستخدم.
  • دعم اتجاه الكتابة RTL/LTR تلقائياً.
  • صفحات مُهيّأة لكل لغة (SEO) بروابط مستقلة لتحسين الفهرسة.

6.2 معالج طلب الإقامة (Wizard)

معالج تفاعلي متعدد الخطوات يجمع بيانات العميل بواجهة سلسة مع مؤشر تقدّم، وقوائم منسدلة مخصّصة، وحالة تحميل عند الإرسال.

6.3 نظام الأخبار

شريط أخبار ديناميكي بارتفاع ثابت لتناسق الصفحة، مع خاصية "عرض المزيد"، وتبديل تلقائي، وترجمة لكل خبر.

6.4 المدوّنة

نظام مدوّنة متكامل مُدار من قاعدة البيانات، مع تصنيفات، وصور غلاف مخصّصة لكل لغة، وبيانات مُهيكلة (Schema) لكل مقال.

6.5 خدمة التذكير + التكامل مع واتساب

نموذج تذكير قبل انتهاء الإقامة (جمع عملاء محتملين)، وأزرار تواصل تفتح واتساب برسالة جاهزة مُعبّأة تلقائياً بلغة العميل تتضمّن اسمه وتفاصيل طلبه.

6.6 بطاقات التسعير

ثلاث باقات خدمات (مبتدئة / كاملة / حزمة الاستقرار) بأسعار وميزات شفّافة، مع خدمات إضافية اختيارية.

7. لوحة التحكم الإدارية

  • إدارة المدوّنة: إضافة/تعديل/حذف بمحرّر غني، مع ترجمة كل مقال في 7 لغات وصور غلاف مستقلة لكل لغة.
  • إدارة الأخبار: نشر مع الترجمات والتحكم بإظهار التاريخ.
  • متابعة الطلبات: عرض طلبات الإقامة والتذكير بنظام لوحة (Kanban) مع عدّاد الأيام المتبقية.
  • رسائل واتساب الذكية: زر لكل طلب يفتح محادثة برسالة احترافية بلغة العميل.
  • الإحصائيات: رسوم بيانية (Chart.js).

10. الأداء والأمان

  • .htaccess: فرض HTTPS، توحيد النطاق، ضغط GZIP، تخزين مؤقت ذكي، ورؤوس أمان.
  • صفحة خطأ 404 مخصّصة بهوية الموقع.
  • معمارية ثابتة تقلّل أسطح الهجوم + HTTPS مفعّل.
  • فصل الصلاحيات عبر RLS في قاعدة البيانات.

11. النشر والاستضافة

  1. بناء نسخة نشر نظيفة تحتوي ملفات الإنتاج فقط.
  2. رفعها على استضافة Hostinger (مجلد public_html).
  3. ربط النطاق ikameti.com.tr المُدار عبر GoDaddy عبر خوادم الأسماء (DNS).
  4. تفعيل HTTPS، وتوثيق الموقع في Search Console، وربط GA4.
  5. الموقع يعمل مباشرة على الإنترنت. ✅

15. الخاتمة

يمثّل مشروع IKAMETI حلاً رقمياً متكاملاً يجمع بين واجهة استخدام حديثة متعددة اللغات، ونظام إدارة محتوى مرن، وبنية خلفية آمنة، ومنظومة تحسين محركات بحث احترافية — وقد تحوّل من فكرة إلى منتج حقيقي منشور وقابل للاستخدام الفعلي على الإنترنت. يعكس المشروع تطبيقاً عملياً لمفاهيم تطوير الويب الحديثة (Jamstack)، وأمن قواعد البيانات، والتدويل (i18n)، وتحسين محركات البحث، وإدارة دورة حياة البرمجيات عبر أنظمة التحكم بالإصدارات.
